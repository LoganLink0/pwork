# PWORK · 个人工作台

> 面向接收者的安装与上手说明见 [发布说明.md](./发布说明.md)；当前内测版本 **0.1.8**（0.x 表示内测期，未到正式定版）。开源仓库：https://github.com/israelberne/pwork

> **一句话定位**：本地优先的四模块个人操作系统——输入 → 处理 → 输出 → **回路**，数据只属于你。
> 建立日期：2026-08-30 ｜ 状态：W0–W5 全部交付，日常使用与迭代中（398 项自动化测试）；简历辅导已拆出为独立项目 RESUME（未开源，见下）

## 快速开始（30 秒）

1. **使用**：双击 [PWORK-Launcher.exe](./PWORK-Launcher.exe)（或 `app` 目录下 `npm run dev`）→ 浏览器自动打开；首访引导五步（含四模块演示视频），信源按 11 个领域共 48 个实测可用源勾选导入
2. **简历辅导（独立应用）**：已迁出为独立项目（独立 git 仓库，未开源），项目目录内双击 `ResumeCoach-Launcher.exe` 或 `npm install`（首次）+ `npm run dev` → `http://127.0.0.1:5274`；也可从 PWORK 首页的「案例」入口进入（内含启动指引）。交接说明见该项目的 `交接文档.md` 与 `AGENTS.md`
3. **可选上云**（7×24 自动抓取 + AI 筛选，免费档 ¥0/月）：双击 `worker\部署向导.cmd`，按中文提示走完（含 Cloudflare 注册引导），再把输出的地址和 Token 填回工作台
4. 前置软件仅 Node.js ≥ 20；所有命令都在**本机终端**于对应目录内执行（详见 [app/README](./app/README.md)、[worker/README](./worker/README.md)（简历辅导的说明在其项目内 README））
5. **可选更安全的 AI Key**：网关随 `npm run dev` / `npm run serve` 自动启动（也可手动 `npm run gateway`）；Key 只存本机 app/.env.local（浏览器接触不到），设 `PWORK_LLM_MODEL` 可固定模型——换厂商不用改应用内任何配置；联网搜索默认复用同一把 Key

## 桌面版说明（2026-10-11 起）

- **单实例**：重复启动会聚焦已有窗口（防两进程写一个库）。
- **AI 网关内嵌**：应用启动即在 127.0.0.1:8788 起网关（开发时若 Node 版网关已占端口则让位）。Key 放置：把 `PWORK_LLM_API_KEY=…`（可选 `PWORK_LLM_BASE_URL=…`）写进 `%APPDATA%/com.pwork.workbench/gateway.env` 后重启应用；用量日志同目录 `gateway-usage.log`。
- **自动备份写磁盘**：到期备份写入 `%APPDATA%/com.pwork.workbench/backups/`（写失败自动回落浏览器下载）。
- 安装器界面为简体中文。

## 发布与更新（给分发规模化的准备）

1. 改版本号：`app/src-tauri/tauri.conf.json` 的 `version`（建议与 app/package.json 同步）。
2. 打包：`cd app && npm run tauri build` → 拿走 `bundle/nsis/PWORK_x.y.z_x64-setup.exe`。
3. **更新器（未启用）**：签名密钥已生成在 `app/.tauri/pwork-updater.key(.pub)`（不入库，**私钥丢失则永远无法推送更新**）。启用步骤：装 `tauri-plugin-updater` → conf 里配 `plugins.updater.endpoints` 指向你的更新源（如 GitHub Releases 的 latest.json）→ 构建时带 `TAURI_SIGNING_PRIVATE_KEY` 环境变量。当前无托管源，故意不接插件——内置一个永远连不上的更新检查比没有更糟。
4. **代码签名（未购买）**：无证书时 Windows 会提示"未知发布者"，属预期；正式分发可购证书后配 `bundle.windows.certificateThumbprint`。
