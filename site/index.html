四模块一个圈

每一轮工作，自动变成下一轮的起点

复盘产出的行动项直接进入待办，勾选完成即闭环——产出回流输入，越用越顺。

输入 记下来 速记浮层随时唤起；11 个领域 48 个实测可用的信源勾选订阅，信息日报自动抓进库。
处理 加工 Ctrl K 一次搜遍全库；条目投票筛选，越用越合你的口味；常用小工具一应俱全。
输出 成稿 周报月报一键汇成，导出 HTML / PPT / 朗读音频；一堆材料直接产出可编辑的演示文稿。
回路 复盘 3 分钟快答复盘产出行动项，自动进任务库；勾选完成即闭环，下周自动带出这一轮。

复盘的行动项回到待办 → 又成为下一轮「输入」——这个圈是自动转的

三条底线

先说清楚什么不做，再说能做什么

数据不出本机

全部数据存在你电脑的本地库里（可随时全量导出搬家）。没有账号体系，没有任何「同步到我们服务器」——因为根本没有我们的服务器。

AI 配不配都行

不配 AI，信息筛选、报告生成全部本地规则完成，功能完整。想增强，用自己的大模型 Key 即刻接入；Key 只写进本机文件，不经过任何第三方。

上云是可选项

想要 7×24 自动抓信源、多设备同步？一键部署你自己的 Cloudflare 云端（免费档 ¥0/月）——部署的是你自己的账号，端点和密钥都归你。
