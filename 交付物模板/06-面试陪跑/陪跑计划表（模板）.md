# 面试陪跑计划表（模板）

> | 项 | 内容 |
> |---|---|
> | 用途 | 高客单陪跑服务的全程计划——明确周期、目标、关键节点，让客户知道每一步在做什么 |

> | 填写方法 | 建档时填基本信息和目标 → 每周更新进度 → 每次面试后填复盘 |

## 阶段一 · 基础打磨（第 1-2 周）

| 事项 | 目标 | 完成标准 | 状态 |
|---|---|---|---|
| 自检包填写与评估 | 完整素材库 | 5 张表全填 + 顾问评估完成 | ☐ |
| 岗位解码 | 目标岗位 JD 全部解码 | P0/P1/P2 + 隐性能力词确认 | ☐ |
| 简历改写 | 一页版终稿 | 客户确认 + 顾问审核通过 | ☐ |
| 匹配度诊断 | 逐条对照打分 | 优势/缺口明确 | ☐ |
| 竞品对位分析 | 目标公司竞品格局 | 面试可讲 | ☐ |
|STAR 库初建 | 3 个完整故事 | 每个有数字/证据 | ☐ |

## 阶段二 · 投递与面试（第 3-8 周）

| 周次 | 目标 | 关键动作 | 面试/复盘 |
|---|---|---|---|
| 第 3 周 | 首轮投递 3-5 家 | 简历按岗位微调 + 投递 | |
| 第 4 周 | 跟进 + 准备面试 | 面试话术卡更新 / 模拟面试第 1 轮 | |
| 第 5 周 | 面试 + 复盘 | 每次面试后 24h 出复盘报告 | |
| 第 6 周 | 追进 + 补投 | 根据面试反馈调整策略 | |
| 第 7 周 | 深入面试 / 终面准备 | 模拟面试第 2 轮（针对进入的终面） | |
| 第 8 周 | offer 谈判 / 复盘总结 | 薪资谈判建议 + 全程复盘 | |

---

## 每次面试后的跟进清单

- ☐ 24h 内发感谢信息
- ☐ 24h 内出面试复盘报告
- ☐ 48h 内更新 STAR 库和量化清单
- ☐ 顾问出下轮面试准备建议
- ☐ 更新陪跑计划表进度
