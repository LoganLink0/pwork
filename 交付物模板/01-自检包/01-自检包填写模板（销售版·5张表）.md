# 自检包填写模板（销售版 · 5 张表 · 深度指导版）

> | 项 | 内容 |
> |---|---|
> | 用途 | 客户自助梳理经历与素材——你填得越具体，简历改得越准 |
> | 填写原则 | 宁可多写后删，不要空着；所有数字凭记忆先填，不用翻旧账 |
> | 用法 | 逐表填写 → 每张表有填写指导 → 不确定就先写想法，顾问会帮你提炼 |

---

## 表一 · 基本盘

| 项目 | 内容 |
|---|---|
| 姓名 / 联系方式 | （投递前再填，先匿名） |
| 年龄 / 城市 | |
| 现公司 | （公司名 + 一句话说清它做什么、行业地位） |
| 现岗位 / 年限 | |
| 薪酬结构 | （底薪 + 提成/奖金，写结构不写绝对值也行） |
| 汇报对象 / 团队规模 | |

### 表一填写指导

- **现公司那句话最关键**——不是公司介绍，是"我在这个公司做什么"的一句话定位。例如："我做的是帮助连锁餐饮企业用 SaaS 系统管理外卖订单"——这句话决定了 HR 第一秒对你的判断。
- **薪酬结构**：如果不便写绝对值，写比例也可以（如"底薪 40% 提成 60%"），改写时只需要知道你的收入驱动力是什么。
- **团队规模**：如果你带人，这是管理能力的硬证据；如果你不带人，写你日常协作的团队角色。

### 常见错误

| 错误 | 为什么不行 | 改成 |
|---|---|---|
| "一家互联网公司" | 太泛 | "AI SaaS 公司（B 轮，200 人），做智能客服" |
| "销售" | 所有销售都叫销售 | "大客户销售，负责华南区 KA 线" |

## 表二 · 业绩数据（近 3 年）

| 年度 | 指标（quota） | 完成情况 | 团队排名 | 最拿得出手的一单 |
|---|---|---|---|---|
| | | | | |

### 表二填写指导

- **指标（quota）是什么**：公司给你定的年度任务额。如果公司没有明确 quota，用你实际完成的总量也可以。
- **排名怎么写**："前 20%"比"第 3 名"更适合简历——因为 HR 不知道你们团队多大，"前 20%"自带规模信息。
- **最拿得出手的一单**：金额最大或最难的那笔。写客户名（可脱敏为行业）+ 金额 + 签约周期。

### 常见错误

| 错误 | 为什么不行 | 改成 |
|---|---|---|
| "完成公司安排的任务" | 没有数字 | "完成 210 万，达成率 117%" |
| "业绩优秀" | 没有对比基准 | "18 人团队排前 5" |
| "完成率 100%" | 100% 看起来像刚好及格 | 实际超过 100% 就写 117% |

## 表三 · 客户与案例库（挑 3 个代表案例）

| | 案例 1 | 案例 2 | 案例 3 |
|---|---|---|---|
| 客户行业 / 规模 | | | |
| 你负责的部分 | | | |
| 单子金额 / 周期 | | | |
| 最大的困难 | | | |
| 结果与证据 | | | |

### 表三填写指导

- **挑哪 3 个**：金额最大的一个 + 最难的一个 + 最能代表你目标岗位方向的一个
- **"你负责的部分"最关键**：同一笔单子里，你是初规件推动者、POC 设计者、还是谈判拍板者？写清楚。
- **"最大的困难"是面试的主角**：简历里写结果，面试讲过程。这个过程越真实，你的可信度越高。
- **"结果与证据"**：签了不是结果。签了之后客户有没有续约？有没有转介绍？有没有扩容？这些才是证据。

### 常见错误

| 错误 | 为什么不行 | 改成 |
|---|---|---|
| 三个案例都是同类客户 | 看不出你的能力宽度 | 至少换一个行业或客户规模 |
| "配合团队完成" | 你做了什么？ | 写你具体做的事："设计 POC 方案" |
| 只写结果不写过程 | HR 无法判断难度 | 用"最大的困难"展示你解决问题的能力 |

## 表四 · 能力自评（1-5 分 + 一个证据）

| 能力 | 自评 | 支撑证据（一句话） |
|---|---|---|
| 获客 / 线索开发 | | |
| 需求挖掘 | | |
| 方案与演示 | | |
| 谈判与成交 | | |
| 回款与客户维护 | | |
| 跨部门协调 | | |

### 表四填写指导

- **自评不用谦虚也不用吹**：3 分 = 正常水平，4 分 = 强项，5 分 = 这个能力是你被同事认可的核心标签。
- **证据必须是一句话的事实**，不是形容。"我擅长沟通"不算；"曾把一个拒绝三次的客户通过持续输出行业报告变成签单客户"才算。
- **获客能力**：你的新客户从哪来？陌拜、转介绍、展会、线上内容？来源越多样，分数越高。

### 常见错误

| 错误 | 为什么不行 | 改成 |
|---|---|---|
| 全部打 4 分 | 没有区分度，HR 无法判断你的强项 | 敢于给自己打 2 分——诚实的短板比虚假的全面更可信 |
| 只写分数不写证据 | 自评无凭无据 | 每一分配一句话的具体事实 |

## 表五 · 目标与恐惧点

| 项目 | 内容 |
|---|---|
| 目标行业 / 公司类型 | |
| 目标岗位 | |
| 招聘链接（如有） | |
| 最担心的面试问题（3 个） | |
| 不想写进简历的内容 | |

### 表五填写指导

- **目标越具体，简历越锋利**："投一家更大的公司"不如"投一家有自研产品的 AI 公司做大客户销售"——前者你什么都要写，后者你知道该突出什么。
- **恐惧点是面试准备的靶子**：你现在最怕被问到的问题，就是简历里要提前埋好答案的地方。比如怕被问"为什么离职"——简历里就要有一段经历能自然解释动机。
- **不想写的内容**：写出来，顾问帮你判断是否可以回避、回避后是否有风险。

### 常见错误

| 错误 | 为什么不行 | 改成 |
|---|---|---|
| 恐惧点写"怕面试不好" | 太泛，等于没写 | "怕被问'你为什么频繁跳槽'" |
| 目标写"更好的平台" | 无法指导简历改写 | "想做 AI 方向的 KA 销售，目标公司产品已过 PMF" |
