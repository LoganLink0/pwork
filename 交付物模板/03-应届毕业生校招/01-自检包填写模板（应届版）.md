# 应届毕业生自检包（校招版 · 5 张表）

> | 项 | 内容 |
> |---|---|
> | 用途 | 应届生自助梳理校园经历与实习素材——你填得越具体，简历改得越准 |
> | 填写原则 | 校园经历不等于"没经历"——组织一场 200 人的社团活动和管理一个 50 万的项目，底层能力是一样的 |
> | 用法 | 逐表填写 → 每张表有填写指导 → 不确定就先写想法，顾问会帮你提炼 |

### 表一填写指导

- **目标岗位越早填越好**：校招简历不需要"一份简历投所有"——投产品岗和投管培生，突出的经历完全不同。先填目标，才知道后面每张表该往哪个方向偏。
- **校园角色**：不是所有头衔都要写——挑和你目标岗位最相关的 2-3 个。想做产品就突出"组织了xxx活动"，想做销售就突出"拉了xxx赞助"。

### 常见错误

| 错误 | 为什么不行 | 改成 |
|---|---|---|
| 什么角色都列 | HR 找不到你的主打方向 | 只列和目标岗位最相关的 2-3 个 |
| "GPA 3.2/4.0" | 除非 3.5 以上或专业前 20%，否则不写 | 用其他更有说服力的经历替代 |

## 表二 · 实习经历（每段实习一张）

| 项目 | 内容 |
|---|---|
| 公司 / 岗位 | |
| 实习时长 | |
| 做了什么（3 件事） | |
| 有没有数字 | （多少用户/多少营收/多少效率提升/多少转化） |
| 有没有作品 | （报告/方案/数据表/公众号文章/代码） |
| 带教老师评价（凭记忆写） | |

### 表二填写指导

- **实习是应届简历的硬通货**——哪怕只做了一个月，只要你能说出具体做了什么、有什么结果，就比空泛的"校园经历"有说服力。
- **"3 件事"的写法**：不要写"协助完成日常工作"——写你做过的最有代表性的一件事，越具体越好。"竞品分析报告被部门采用"比"协助市场部工作"有用一百倍。
- **数字不用大**：实习生的数字天然不大，"整理了 200 条客户反馈并分类"比"协助运营"有力得多。

### 常见错误

| 错误 | 为什么不行 | 改成 |
|---|---|---|
| "协助XX部门日常工作" | HR 不知道你做了什么 | "整理了 200 条客户反馈并按痛点分类，产出 3 条产品优化建议" |
| "参与了XX项目" | 参与不等于做了 | "负责XX项目中的竞品调研模块，输出 30 页报告" |

## 表三 · 校园经历（挑 3 个最有含金量的）

| 项目 | 校园活动 1 | 校园活动 2 | 课程项目 / 比赛 |
|---|---|---|---|
| 名称 / 你的角色 | | | |
| 团队规模 | | | |
| 做了什么（具体动作） | | | |
| 有没有数字 | （人数/金额/名次/覆盖面） | | |
| 有没有作品 | | | |

### 表三填写指导

- **社团/学生会经历的关键不是头衔**，是你实际组织了什么、遇到了什么困难、怎么解决的。"担任学生会宣传部部长"不如"组织了一场 500 人参与的迎新晚会，负责赞助商洽谈，拉到 8000 元赞助"。
- **课程项目/比赛**：如果你的课程项目做出了实际成果（报告被采用、比赛获奖、产品上线），这就是你的"项目经历"——把它当实习写。

### 常见错误

| 错误 | 为什么不行 | 改成 |
|---|---|---|
| 只写头衔不写做了什么 | "部长""主席"头衔千篇一律 | "组织了一场 500 人的迎新晚会，负责赞助商洽谈和流程设计" |
| 把所有活动都列上 | 没有重点 | 只挑和目标岗位最相关的 2-3 个 |

## 表四 · 能力自评（1-5 分 + 一个证据）

| 能力 | 自评 | 支撑证据（一句话） |
|---|---|---|
| 学习能力 | | |
| 沟通表达 | | |
| 组织执行 | | |
| 数据 / 分析 | | |
| 团队协作 | | |

### 表四填写指导

- **应届生的能力评估和职场人不同**：HR 不指望你有职场技能，但会看你的**可迁移能力**——学习能力、沟通、执行力是三大核心。
- **学习能力**：不是 GPA——是"你快速学会了一件事并产出了成果"的证据。比如"两周自学 Python 并完成了一份数据分析报告"。
- **每条证据必须是具体的事实**，不是"我觉得我学习能力比较强"。

### 表五填写指导

- **恐惧点是面试准备的靶子**：应届生最怕的是"没有经验"——但你实习过、组织过活动、做过项目，这些都是经验。写下你怕被问的，我们逐条准备应答。
- **"不确定要不要写的"**：写出来，顾问帮你判断。
