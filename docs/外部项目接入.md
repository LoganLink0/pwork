# 外部项目接入 PWORK（三步）

> 面向 PWORK 仓库之外的同机项目（如 RESUME / MIND / MetaVault）：让它们把「做了一件事」写进 PWORK 的速记与待办。
> 通路是 PWORK 桌面版的本机网关（127.0.0.1:8788）——只增不删、令牌授权、失败人话报错。
> 试点先例：RESUME 的「同步案例进展到 PWORK」（server/routes/pwork.ts），照抄即可。

## 三步接入

### 第一步：暴露你项目的调用入口

在你的项目里加一个转发端点（建议放在本机 sidecar/服务端，**不要放在浏览器页面里直连**——
令牌不进网页层，且 PWORK 网关的 CORS 白名单不含其他项目）：

```
POST http://127.0.0.1:8788/api/v1/library/notes   （追加速记）
POST http://127.0.0.1:8788/api/v1/library/tasks   （创建待办）
请求头：Content-Type: application/json
        Authorization: Bearer <令牌>
notes 载荷：{ "body": "正文（必填）", "title": "标题（可选，缺省取正文首行）", "tags": ["标签"] }
tasks 载荷：{ "title": "标题（必填）", "due": "YYYY-MM-DD（可选）", "recurrenceDays": 7（可选：1/7/14/30/90） }
```

响应：成功 `{ "ok": true }`；失败带人话 `error`（401 令牌不匹配 / 400 字段不合法 / 429 每分钟 30 次限速）。

### 第二步：拿令牌并配到你的项目

打开 PWORK → 设置 → 数据 → **外部接入**，复制接入令牌，配到你项目的启动环境：
`PWORK_LIBRARY_TOKEN=<令牌>`。令牌变更后同步更新即可（PWORK 重启不会换令牌）。

### 第三步：注册动作或工具（可选）

- 希望在 PWORK 的命令面板/轮盘里出现你的工具入口：在 PWORK 仓库 `engine/actions.ts` 登记一条动作
  （契约测试会校验字段完备）；
- 希望外部 AI 客户端（支持 MCP 的助手）写 PWORK：MCP 薄壳已随安装器分发在 `安装目录/mcp/pwork-mcp.mjs`，
  MCP 客户端配置 `command=node`、`args=[该路径]` 即可。

## 边界与约定

- **只增不删**：接口第一版只有速记追加与待办创建；删除/修改请在 PWORK 界面人工完成。
- **进程外组合**：交互走 HTTP/文件/命令行，不做运行时加载外部代码（供应链红线）。
- **版本化**：破坏性演进走 `/api/v2/...` 新路径，旧路径保留一个弃用周期。
- **失败语义**：网络不通/令牌错/限速都会带人话 error 返回；调用方应展示而不是吞掉。
