## 一分钟现状

PWORK 是本地优先的个人工作台（输入/处理/输出/回路四模块），React 19 + Vite 8 + Tauri 2 桌面壳 + SQLite 主库（桌面版迁移体系完成，0.1.12 起）。当前事实：

1. **版本**：**0.1.24-fix2 已装机未发布**（胶囊岛幻影终修；0.1.24-fix 与其同段其余内容见下）（含宽幅整改三批 + 胶囊岛命中裁剪/自由驻留隐藏 + 配置文件化 + 输入法守卫等全部修复）。已发布最新为 v0.1.22（GitHub Release 双包）。**0.1.23 与 0.1.24/0.1.24-fix 均未发布**——0.1.24 段 CHANGELOG 已备，发布时走 docs/发版同步清单.md 九段。
2. **分发**：GitHub 公开仓库 `LoganLink0/pwork`（MIT）· Release v0.1.22 双包在线 · 大陆下载 COS 直链 · 介绍页 https://loganlink0.github.io/pwork/（源在 docs/，push 即更新）· Gitee 镜像。
3. **本段新机制（新会话必知）**：
   - **宽幅布局**：content-inner 宽度由 App 壳 `WideContent` 组件按路由清单（九前缀）显式挂 `wide-host` 类（**:has 已弃用**——部分 WebView2 环境不生效，复盘 3.76）；页面根类 `content-wide` + 变量式 `--container-w`（.settings/.review-root .container 等自限宽类不与之抢特异性）。右栏 300px sticky，≥1440 显示、窄窗**折行到主列下方**（不隐藏，信息不丢）。
   - **配置文件化**：用户设置（主题/AI 接入/键位/备份/胶囊岛）存数据目录 prefs.json，Rust prefs_read/prefs_write 原子写 + 前端写队列串行化 + `pwork-prefs-changed` 事件跨窗广播；localStorage 双写为兼容期回落，浏览器版不受影响。**跨窗一致性**：伴生窗事件入口用 `refreshPrefsFile()`（失效+重拉一体）await 后再同步读——只失效不重拉，同步读会撞 null 缓存回落 localStorage 旧值（stale cache 与回落值过期是同源两病，2026-11-18 晚根治）。挂载读位置先 await readPrefsFile 预热（竞速曾回落分叉的 localStorage 旧值）。
   - **胶囊岛探边条形态（2026-11-20 终版，用户拍板「直观可见」，复刻 0.1.23 显眼形态）**：缘停靠收起=**横条探边条**——窗体保持画布尺寸、原子定位到探边位（top 露条底 24px 贴顶居中 / right·left 露条侧 24px 贴缘），横条本体可见（岛在哪一眼可见，此前 40px logo 半截在壁纸上=隐形）；展开=完整横条；滑入滑出动画由**条内 translate** 承担（窗体只原子定位，条内反向偏移起步→过渡回原位，像素连续无闪现）。自由驻留=72×72 小窗 logo 满窗原地驻留（**logo 必须落在小窗可见区 (4,4)**——曾停在画布位致小窗全透明空窗、把手不可见，像素采样定位）。一切尺寸/位置变化=单次 SetWindowPos 原子变形（hide→show 禁用=蓝色窗体闪现；双步 set_size→set_position 禁用=60ms 中间矩形）。命中区=屏内可见部分（探出屏外部分收不到点击，无需 region——region 与可见窗变形是白闪/幻影蓝窗根因，已移除）。**生命周期指令禁 rAF**（遮挡判定限流 0Hz 静默丢弃），全部直调 invoke。呼出=靠近探边条滑出；离开 1 秒滑回；收起态单击条=展开并保持（120ms 内点在悬停自动展开前=真实收起态单击路径）。**logo 右键菜单三项**：「隐藏到屏幕上方/右侧/左侧」——`isle_stash_to` 原子落探边位并返回落位供持久化；菜单开启前 `isle_grow(mode,y)` 变形到展开位（菜单必须完整在屏内；自由驻留按 logo 锚原位长回，**画布态直接保留原位**——相对锚定须配尺寸守卫，否则 peek/grow 循环累计漂移 224px/次）；**lib.rs 注册表与命令同名同存删**。拖拽落点判定=光标基准；**收起计时器等异步回调读模式一律走 modeRef**。prefs 事件入口用 refreshPrefsFile（失效+重拉一体）；挂载读位置先 await readPrefsFile 预热。
   - **公告卡版本号**：标题取构建版本 `__APP_VERSION__` 动态注入（曾三次漏改，机制化消灭）；亮点一句话仍随版手写（发版清单 B 段唯一人工项）。

## 用户明确的纪律（违反=返工；持续追加；详见 AGENTS.md 与本文历史版）

1. 出错立即暴露 + 错误日志留痕；错误处理不许静默兜底。
2. 界面与文档说人话；禁自造词/编号黑话。
3. **不确定必确认**（2026-11-18 强化）：「统一/修复/四页」这类对象不明的指令，动手前补宾语确认句或出改动范围清单过目——三个理解偏差连续返工的教训（复盘 3.78）。
4. **布局类改动必须渲染实测**：CDP 探针读宽度/类名数字后再交付（复盘 3.76）；源码对 ≠ 渲染对。
5. **重装前关停旧进程**（复盘 3.77）；装后核对 exe 哈希/mtime。
6. 所有待办必须写进 TODO.md；多问题反馈**收到即逐条编号入账**（复盘 3.79）。
7. 追问优先：需求不清先问产出给谁/输入是什么/完成标准。
8. 第一性原理优先：更好做法直接指出；方案先回「假如现组件不存在怎么设计」。

## 环境注意（Windows 重灾区，详见复盘第三节）

- 杀进程前先 netstat 查身份：5177/5180/5274/5275 是用户其他项目（Corealize/MIND/RESUME），不是本项目的；本项目杀 5273/8788 前先确认 PID 归属。
- Git Bash 的 curl 发中文是 GBK——测网关中文请求用 `--data-binary @utf8文件`（复盘 3.16）。
- **改 vite.config.ts 必须一次编辑成型**——watcher 读到中间态会崩 dev server（复盘 3.19 第三坑）；vitest 环境已守卫不会误拉网关。
- **子进程用 fork + stdio:'ignore'**：从 vite 进程 spawn 继承控制台在 Windows 下 0xC0000142（复盘 3.19 第一坑）。
- IAB 浏览器 evaluate 在隔离世界；locator.click 卡可操作性时用 `locator.evaluate(el => el.click())` 兜底（复盘 2.8）。IAB 的 localStorage/IndexedDB 是独立测试档案，别当用户真实数据。
- 源文件一律用编辑工具写（Mimosa 钩子拦 Bash 写源码与 heredoc/脚本改文件）；提交信息里出现文件名字样可能误触发钩子，拆开跑即可。
- **FS Access（目录授权）只在安全上下文可用**：手机连的局域网地址页面没有该能力，扫描等操作须在 `127.0.0.1:5273` 上做。
- **node execSync 调 powershell 用 Windows 风格路径**（`E:/...` 正斜杠可用；`/e/...` MSYS 路径 powershell 不识别）。
