## 环境注意（Windows 重灾区，详见复盘第三节）

- 杀进程前先 netstat 查身份：5177/5180/5274/5275 是用户其他项目（Corealize/MIND/RESUME），不是本项目的；本项目杀 5273/8788 前先确认 PID 归属。
- Git Bash 的 curl 发中文是 GBK——测网关中文请求用 `--data-binary @utf8文件`（复盘 3.16）。
- **改 vite.config.ts 必须一次编辑成型**——watcher 读到中间态会崩 dev server（复盘 3.19 第三坑）；vitest 环境已守卫不会误拉网关。
- **子进程用 fork + stdio:'ignore'**：从 vite 进程 spawn 继承控制台在 Windows 下 0xC0000142（复盘 3.19 第一坑）。
- IAB 浏览器 evaluate 在隔离世界；locator.click 卡可操作性时用 `locator.evaluate(el => el.click())` 兜底（复盘 2.8）。IAB 的 localStorage/IndexedDB 是独立测试档案，别当用户真实数据。
- 源文件一律用编辑工具写（Mimosa 钩子拦 Bash 写源码）；提交信息里出现文件名字样可能误触发钩子，拆开跑即可。
- **FS Access（目录授权）只在安全上下文可用**：手机连的局域网地址页面没有该能力，扫描等操作须在 `127.0.0.1:5273` 上做。
