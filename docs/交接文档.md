   - **胶囊岛语义规格 T1–T8（2026-11-21 用户定案，取代 2026-11-20 的 S1–S8——触碰任一条目必须先申报）**：
     **T1** 锚点=收纳态专属形态，只存在于贴边带（近顶 ≤120px / 近左右缘 ≤80px，CSS px）：贴顶=横排胶囊 100×32 贴顶居中（离屏顶 16px，与展开后横条内 LOGO 白圆纵坐标对齐）；贴缘=竖排 44×100 贴缘（贴缘侧直角，纵向落点跟随、钳屏内完全可见）。**非贴边区没有锚点**（屏上只有本体横条）。
     **T2** 自由驻留=稳定态：拖横条/锚点到非贴边区松手，本体横条 320×84（无按钮紧凑条）原位驻留，屏上只有胶囊岛，光标离开**不收回**（光标监视只属于临时展开，自由驻留/收纳/隐藏必须停监视）。
     **T3** 展开（顶站位）：本体 tl = 锚点 tl + (-16,-26)·缩放——锚点白 P 圆中心与横条 LOGO 白圆中心重合=「LOGO 位置不变」（像素级实测）；缘站位：横条在屏内侧展开（间隙 2px），纵向中心对齐锚点中心；呼出语义=必可见。
     **T4** 交互：悬停锚点 280ms 呼出（快速划过不呼出）；光标在横条上保持；离开 1 秒回收纳态；单击锚点=立即呼出。**落位收纳后 1.2s 呼出抑制**（落点=光标所在，锚点恰在光标下，不抑制则收纳粘不住落点——实机实测回弹；限时 grace 防旧版「落位抑制吃掉悬停展开」复发）。
     **T5** 拖拽落点统一定形态：贴边带内→收纳（顶横排/缘竖排），非贴边→自由驻留；判定一律光标基准、moved=光标位移 ≥3px。锚点交互全部由 Rust 驱动：悬停/按下=交互线程轮询（GetAsyncKeyState），拖拽跟手=低级鼠标钩子（WH_MOUSE_LL，安装与消息泵必须同线程）——WebView2 对经历隐藏循环的窗不再派发 mousedown（实测），页面侧锚点交互整类消灭，锚点窗=纯渲染视图。
     **T6** 横条上无按钮（用户拍板）：原地点击 LOGO 区（条内左端 64px）=问小 P，其余部位=打开 PWORK，按住拖动=换位置——分派在 Rust `isle_body_drag_start`（按下位置+位移判定）。
     **T7** 设置卡：开关「开」=`isle_restore` 恢复持久化状态（**恢复前必须 refreshPrefsFile 重拉**——位置由伴生窗拖拽落位写入，主窗缓存陈旧会让关→开跳回启动旧位，实机复现已修）；「关」=锚点+本体全隐藏；「重置」=顶部收纳归位。位置持久化两窗互备双写（savePos 幂等），重启恢复原站位。
     **T8** 收纳物在任何壁纸/任何显示缩放下必须真实渲染可见（像素层验收强制，禁止空窗/隐形）。窗体显隐=show/hide 即时切换（无 morph）；**set_size 与 place 只在隐藏状态做**（显示中的重排会让 WebView2 停止派发 mousedown——多轮返工真凶）；一切定位用客户区语义（Win11 无边框窗外框≠客户区，place_at 按 client_origin 精确补偿；创建态客户区比画布大 (16,9)，恢复/展开时 set_size 归一）；生命周期指令禁 rAF（遮挡判定限流 0Hz 静默丢弃），全部直调 invoke。

## 环境注意（Windows 重灾区，详见复盘第三节）

- 杀进程前先 netstat 查身份：5177/5180/5274/5275 是用户其他项目（Corealize/MIND/RESUME），不是本项目的；本项目杀 5273/8788 前先确认 PID 归属。
- Git Bash 的 curl 发中文是 GBK——测网关中文请求用 `--data-binary @utf8文件`（复盘 3.16）。
- **改 vite.config.ts 必须一次编辑成型**——watcher 读到中间态会崩 dev server（复盘 3.19 第三坑）；vitest 环境已守卫不会误拉网关。
- **子进程用 fork + stdio:'ignore'**：从 vite 进程 spawn 继承控制台在 Windows 下 0xC0000142（复盘 3.19 第一坑）。
- IAB 浏览器 evaluate 在隔离世界；locator.click 卡可操作性时用 `locator.evaluate(el => el.click())` 兜底（复盘 2.8）。IAB 的 localStorage/IndexedDB 是独立测试档案，别当用户真实数据。
- 源文件一律用编辑工具写（Mimosa 钩子拦 Bash 写源码与 heredoc/脚本改文件）；提交信息里出现文件名字样可能误触发钩子，拆开跑即可。
- **FS Access（目录授权）只在安全上下文可用**：手机连的局域网地址页面没有该能力，扫描等操作须在 `127.0.0.1:5273` 上做。
- **node execSync 调 powershell 用 Windows 风格路径**（`E:/...` 正斜杠可用；`/e/...` MSYS 路径 powershell 不识别）。
