设计理念

为什么是字母 P？因为它同时是三样东西

很多人问那个橙色的圆标是什么意思。答案很简单：它是一只耳朵，一只伸出的手，也是 Partner 的首字母——这三件事，就是 PWORK 的全部设计哲学。

它是一只耳朵

PWORK 学会的第一件事是「听」：你随手速记的、订阅抓来的、开会时说的，它都默默收好、整理成档。但它只在你自己的电脑里听——你的话，不出门。

它是一只伸出的手

圆圆的手掌向上摊开，是「递东西」的姿势：每天一份信息日报、一键成稿的周报和 PPT、复盘后自动排队的行动项——都是它整理好，伸手递到你面前的。

它是 Perfect Partner——完美搭档

P 也是 Partner 的 P。它不是一台催你干活的效率机器，是一个只属于你的工作伙伴：不注册、不上传、开源免费，打算陪你很多年。应用里那个常驻的橙色圆钮，就是它——有事随时「问小 P」。

所以下次看到这个橙色的 P，希望你想起的不是「一款软件」——是那个一直在你电脑里、听你说、帮你做的伙伴。

01
四个部分，一个循环

每一轮工作，自动变成下一轮的起点

复盘列出的行动项自动进待办，做完打勾就算完成——这一轮做出来的东西，自动变成下一轮的素材。

第一步 记下来 速记窗口随时唤起，想到什么写什么；任何应用里复制文字一键存为速记，粘贴视频链接自动解析入库；从 80 个亲测可用的信源里挑想要的，也能直接订阅 B站 UP 主，每天自动收成一份信息日报。
第二步 加工 按 Ctrl K 一次搜出所有内容；文章点开就是全文，不再是干巴巴的摘要，划一段直接存进速记；读过的投一票，筛选越来越合你的口味；配上 AI 还能对整个库提问，回答带出处。任务完成与到期提醒都有通知留痕，顶栏铃铛随时回看。
第三步 成稿 周报月报一键生成，可下载、可导出 PPT、还能转成朗读音频；一堆材料也能直接变成能编辑的 PPT。
第四步 复盘 3 分钟做完一次复盘，行动项自动进待办；做完打勾，下次复盘自动接着这一轮继续。

复盘的行动项自动进待办 → 做完的成果又变成下一轮的素材——这个循环是自动的

02
三条原则

先说清楚什么不做，再说能做什么

数据不出你的电脑

全部数据都存在你自己的电脑里，随时可以打包搬到新电脑，也可以导出成一份能直接阅读的文件夹。没有账号，也没有「同步到我们服务器」这种事——因为根本没有我们的服务器。

AI 配不配都行

不配 AI，信息筛选、报告生成全部用你电脑上的规则完成，功能完整。想用 AI，把自己在大模型平台申请的 Key 填进来就行；Key 只写进你电脑上的文件，不经过任何第三方。

云端是可选项

想要全天候自动收信源、多设备同步？在你自己的 Cloudflare 账号里装一套就行（免费档每月 0 元）——装在你自己的账号下，地址和密钥都归你。

04
软件外面

免费开源，不该等于没人管

很多人对开源软件的担心是：作者扔下一个链接就消失了。PWORK 不这样经营——下载、更新、提问、看记录，每一步都有人在维护。

下载不用翻墙

安装包放在国内对象存储上，直链下载，不等 GitHub 的龟速；发布页挂着校验值，下载完可以对一遍再装。

装上以后自动更新

出新版本，应用里一键升级，更新通道同样走国内直连——装完这一次，后面不用再手动下载。

两个系统一起发

Windows 与 macOS 安装包同一时间发布，macOS 的包由云端自动构建，不会让你等「另一个平台的版本还没出」。

大陆看代码也顺畅

代码在 Gitee 同步镜像，网络不畅时看源码、提问题都不受影响。

每一版都有说明

八个版本，每一版改了什么都写在发布说明里，改了什么、没改什么，历史记录全部可回溯。

提问有人回

常见问题

问得最多的五件事

我的数据存在哪里？换电脑怎么办？

全部数据存在你自己的电脑里。换电脑：在设置里点「全量导出」得到一个备份文件，新电脑上「导入」即可；也可以导出成一份能直接阅读的文件夹（每条记录一个 Markdown 文件）。

必须配置 AI 才能用吗？

不必须。不配 AI 时信息筛选、报告生成全部用本机规则完成，功能完整。想用 AI 时，把自己在大模型平台申请的 Key 填进应用即可，支持 16 家厂商，Key 只写进你电脑上的文件。

首次打开 Windows 提示「已保护你的电脑」、macOS 提示「已损坏」——软件有问题吗？

软件没有问题，这是系统对「没有注册开发者身份的软件」的固定提醒——我们还没向微软、苹果支付每年数百美元的签名费用（内测阶段暂不购买，正式版会处理）。PWORK 是开源软件，安装包里的内容任何人都可以自行核对。放行方式：Windows 点「更多信息」→「仍要运行」；macOS 先打开一次（会提示已损坏），到 系统设置 → 隐私与安全性 点「仍要打开」，或按发布页给出的终端命令放行。

云端同步是必须的吗？数据会不会上传？

不是必须。不配置云端，一切功能照常、数据永不离开你的电脑。想要多设备同步与全天候自动收信源，需要在你自己的 Cloudflare 账号里部署一套（免费档），应用提供一条命令的引导部署。

软件免费，后续会收费或加广告吗？

代码 MIT 许可全部公开，界面无广告、无账号体系、无遥测。这个立场写在仓库里，代码就是证据。
