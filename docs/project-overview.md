## 是什么

PWORK 是**本地优先**的个人工作台：速记、信息日报、任务目标、复盘这些个人数据全部存在你自己的设备上，无账号、无服务器、无遥测。四个模块构成一条闭环：

**输入**（捕获：速记 / 信息日报 / 信源 / 条目库 / 外部数据）→ **处理**（加工：文字/音频/图片工具箱、跨模块检索、AI 问答）→ **输出**（产出：周报 HTML/PPT、朗读音频、数据卡片、文章草稿）→ **回路**（复盘：CLAP 复盘工作台，结论生成行动项回任务库，形成下一轮输入）。

外加「案例」入口（跳转独立项目 resume-coach，简历辅导工作台——按第一性原理从 PWORK 拆出）。

## 给谁用

个人使用者（自己 + 伙伴，单机）；可分发给任何有同类需求的人。设计假设：数据敏感、不信任云、愿意为"数据属于自己"承担自己备份的责任（应用用自动备份 + 迁移指引把这个责任降到最低）。

## 数据与隐私立场

- L1 本地为默认：所有数据在本机——桌面版为应用数据目录的 **pwork.db（SQLite）** + vault 镜像 + 附件目录，网页版为 IndexedDB。
- L2 外发明示：AI 功能可选用，发什么、发往哪在设置页明示；Key 只存本机，永不进备份。
- L3 云同步为可选项：需要者自部署 Cloudflare Worker，包里零预置账号。

## 已知边界

Windows 首次运行无签名安装包会提示"未知发布者"（点更多信息→仍要运行，发布说明有写）；信息日报部分源走公共转接服务偶尔慢。
