> 扫描对象：`app/src`（跳过文档与测试文件）。

## 首扫发现（4 处，同一类）

**ime-safe-enter-submit ×4**——输入框 / 文本域的 Enter 键监听未检查 `event.isComposing`，中文输入法选词时按回车确认候选词会误触发提交动作。四个命中点全是中文文本输入场景（筛选命名、因果图节点、会议速记卡、目标进度），对本产品的中文用户是真实功能缺陷；全仓 `isComposing` 使用数此前为零，属整类潜伏。

## 修复（2026-11-15，四处同批）

四处 `onKeyDown` 均补一行守卫（MWG 的 Drop-when 判据：查 `isComposing` 即豁免）：

```tsx
if (e.nativeEvent.isComposing) return // 中文输入法选词回车不触发
```

落点：`Items.tsx`（保存筛选）/ `CldBuilder.tsx`（加节点）/ `CollectPanel.tsx`（加速记卡）/ `Goals.tsx`（提交进度）。复扫 **0 findings**（33 条确定性规则全过）。

## 生态观察（2026-11-17 追加）：A2UI——Agent 生成界面的协议

调研定位 [a2ui-project/a2ui](https://github.com/a2ui-project/a2ui)（17.5K★，Google 主导，Apache-2.0，[规范 v1.0](https://a2ui.org/specification/v1.0-a2ui/)）：Agent 流式传输**声明式界面描述**（JSON 数据，非代码），应用用 React / Angular / Lit / Flutter / SwiftUI / Jetpack Compose 原生组件渲染；Basic Catalog 内置 18 个组件（Text/Image/Button/Card/Tabs/Modal/TextField/CheckBox/ChoicePicker/Slider 等）+ 15 个内置函数，目录可用 allowedParents/allowedChildren 声明合法嵌套，schema 强制验证（禁任意可执行代码过信任边界）。

**与本项目的关联**：PWORK 的 AI 输出（复盘教练、大纲、调研报告）目前是 Markdown 文本流；若未来要让 AI 直接产出**结构化交互界面**（行动项确认表单、大纲树、参数化卡片），A2UI 是行业标准协议的候选——Agent 只能从受控目录组装、边界由 schema 保证，与「AI 配不配都行」的克制原则不冲突（无 A2UI 渲染器时退回文本流，属增强层）。**不建议现在接入**：新依赖需单独批次（依赖纪律），且产品侧先要有「AI 产交互界面」的真实需求；登记为生态观察，届时再评估 `@a2ui/react`。
