# user-guide.md · 面向使用者的功能说明

> 应用内同款内容在「帮助」页（含配置指南）；本文档是离线版。安装与首用见 [发布说明.md](../发布说明.md)。

## 首次使用

第一次打开自动进入全屏分步引导，五步走完（或点跳过）才进入主界面：① 认识工作台——四个模块各一段应用内实拍的演示视频，循环播放（输入/处理/输出/回路）；② 信源初始化——按领域挑选要订阅的信源（12 个领域、80 个实测可用源，勾选导入）；③ 采集偏好——写下你关注什么、讨厌什么；④ AI 功能（可选）——不配完全可用；要配的话选厂商（16 家）、去官网拿 Key 粘贴保存即测试，Key 只存本机文件。⑤ 可选上云——想 7×24 自动抓取的人在这里配（桌面版一键部署全程在应用内跑，完成自动回填端点与凭据），不需要可跳过。想重看：设置 → 关于 → 「重看首访引导」。

## 工作台首页

打开应用第一屏：问候与今日概览、三张状态卡（信息日报 / 到期待办 / 复盘节奏——有数据的卡主导，空态卡虚线引导）、四模块直达卡、最近速记。`N` 键随时唤出速记浮层（`Esc` 存草稿）。

## 输入 · 捕获

- **速记**：三栏编辑器（标题/正文/前沿元数据），标签、转待办、挂到复盘、条目互链；列表按自然日分组（今天/昨天/N月N日），编辑器带 Markdown 预览（预览/编辑一键切换）与字数行数；删除进回收站，可恢复、可彻底删除（超过 30 天自动清理）。
- **图片附件**（桌面版）：聊天截图、合同页等直接 `Ctrl+V` 粘进速记——按 `N` 唤起速记浮层或打开任意一条速记的编辑器，粘贴后图片立即存为本机附件（一条最多 10 张、单张不超过 20MB），正文可以照常写也可以只存图。附件以缩略图形式呈现在速记的阅读视图里，列表里带 📎 角标；导出「可读档案」时附件原文件一并打进压缩包。图片里的文字识别交给系统工具（如 PowerToys 的文字识别），应用不内置。
- **剪贴板速记**（桌面版）：在任何应用里复制一段文字后按 `Ctrl+Alt+V`，内容立即存为一条速记并弹系统通知确认——看到就摘，不用切窗口。键位可在 设置 → 键盘快捷键 改；剪贴板里没有文本时会提示。
- **视频链接入库**（桌面版，工具箱 → 视频）：粘贴 B站 / YouTube / 抖音等视频链接，自动解析标题、作者与简介后存入条目库（可检索、可投票、评分靠前进日报）；打开时自动预填剪贴板里的链接，重复链接按链接+标题去重。需本机安装 yt-dlp，解析全程在本地完成。
- **条目阅读视图与摘录**（桌面版与网页版）：条目卡和日报卡上有「阅读全文」按钮——点开是固定阅读窗（不跳浏览器），抓到的正文纯文本就地阅读（打开即抓，抓取中显示进度；登录墙等抓不到的会如实说明，可手动重试）。划选正文会浮出操作条：**摘录到速记**（自动带出处与原链，挂回本条目）与复制。正文全文支持跨模块检索（命令面板搜正文字词也能命中）。条目正文的抓取在打开应用后按队列自动补齐（每轮最多 20 篇、温和限速），新抓完一轮会有通知。
- **信源管理**：添加/编辑 RSS 源（T1/T1.5/T2 分级=信源权重，分级由你的投票自动升降）、多推率列展示各源近 60 天的投票依据、「推荐信源目录」按 12 个领域共 80 个源勾选订阅（各领域核心源默认预选，全部实测可达、按地址去重；点信源页「从目录添加」随时可打开）、健康列逐源显示最后错误（并区分「本地网络到不了」与「源可能已停更」）、连败自动停用；只有站点主页地址时用表单里的「自动探测 feed」找地址。**信源自检**（近 30 天产出画像：产出健康 / 噪声偏高 / 零命中 / 观察中）与**引用发现**（你的信源反复转引的非订阅域名，提示为潜在新源）自动出现在信源页。
- **yt-dlp 信源（视频平台投稿）**：添加信源时类型选「yt-dlp 平台投稿清单」，地址填 UP 主投稿页（如 `https://space.bilibili.com/UP主ID/video`）或 YouTube 频道视频页——抓取时调用你本机安装的 yt-dlp（需先安装：`pip install yt-dlp`，或从 [yt-dlp GitHub](https://github.com/yt-dlp/yt-dlp/releases) 下载）拉最新 30 条投稿的标题与链接，不下载视频，之后照常评分进日报。已知限制：B站对无登录的列表请求有间歇性拦截（失败重试通常可过；需要稳定可把浏览器导出的 cookies.txt 放进 yt-dlp 配置目录）；B站清单的条目标题受平台接口限制显示为视频编号（BV 号），YouTube 等平台标题完整。微博、AcFun、西瓜视频等 yt-dlp 支持的平台同样可按此方式接入。
- **RSSHub 桥接（进阶）**：对没有 RSS 的平台，可自建 [RSSHub](https://docs.rsshub.app/install/)（Docker 一条命令，部分路由需配置平台 Cookie），把路由地址当普通 RSS 填进信源即可——PWORK 不区分来源，任何满足 RSS 格式的地址都能接。
- **信息日报**：进页自动保鲜——今天还没数据就自动抓一轮（配好云端优先拉云端增量，没配或云端没新货则本地直接抓源站），也可随时点「立即抓取」→ 规则筛出当日 Top 10，卡片左侧标分层（**必看**=当天排前 2、**可看**=第 3–8、**可略**=靠后，不显示分数），条目可三档投票（多推/没想好/少推——自动驱动信源分级升降与 AI 兴趣画像）、批注、标记机会/威胁/趋势、转行动卡、导出 Obsidian 日报格式。没有未读数和红点——看完就处理，不积攒。配了云端时云端按北京时间整点自动抓（默认 9/11/15/18/19/20/23 点，可在 设置 → 云端同步 改）。
- **条目库**：近 30 天全部条目按 stage 筛选，被筛除的标 TTL。
- **外部数据**（周报数据源，入口在 周报导出 页）：手工数据块 + CSV/JSON 文件导入 + 开放推送接口（云端 /api/ingest 拉取），自动并入周报；调研任务的发现在「输出 → 调研分析」管理。

## 处理 · 加工

工具箱：文字（朗读合成、卡片图）、音频（录音转文字、朗读合成）、图片处理；轻量音视频转换推荐外部工具（工具箱内有直达：剪映、HandBrake）。快速启动：常用 AI/网页的自定义入口（内置豆包/DeepSeek 等，可增删，最近使用排前，调研页跳转共用）。全库跨模块检索用 `Ctrl K` 命令面板（速记/条目/任务/洞察一网打尽）。带外部材料的深度调研用输出模块的「调研分析」（可上传 Word/PDF/CSV 整份材料）。

## 输出 · 产出

- **周报导出**：本周/本月素材 + 外部数据块自动成稿，导出 Markdown/HTML/PPT（含幻灯片结构预览）。
- **调研分析**：输入调研目标（公司 / 岗位 / 自由主题）→ 拿到建议调研角度（3 个，内置模板，配了 AI 可定制）→ 「发现」一条流水记到底：一键联网调研自动追加（或复制完整提示词去豆包/DeepSeek 等，整篇回答直接粘贴进来；也可单角度补查）→ 整理成稿，导出 Markdown / Word。任务和发现可随时回来继续；旧版按节保存的发现自动合并成流水。
- **PPT 撰写**：粘贴文字或上传 Word/PDF/Markdown → AI 起草大纲（内部/外部两套措辞）→ 逐页审核修改 → 导出 .pptx（原生文字框可编辑；无 AI 时内置模板兜底）。
- **文章草稿**：速记与洞察按周期聚合 → AI 整理骨架 → 逐节编辑 → 导出 Markdown。
- **朗读音频**：周报转语音，通勤场景用听的回顾。
- **数据卡片**：关键数字生成分享卡片图。

## 回路 · 复盘（CLAP 工作台）

3 分钟快速复盘 / 完整向导（事实→对比→归因→行动）/ 团队复盘会议室 / 档案库 / 认知资产（洞察卡与验证）/ 聚合分析。复盘产出的行动项自动进任务库（if-then 执行意图随行，仪表盘与任务页双向同步闭环）。新建复盘的模板按你过往的使用频次排序。档案库可按场景/类型筛选，支持按月聚合导出全部档案（md）。

认知资产的回访是间隔重复：回答「成立」间隔翻倍（最长 180 天）并计入已验证；「部分失效」一个月后再问；「需要修正」则该认知的回访终结。聚合分析可选 3/6/12 月窗口，含行动闭环率、洞察有效率与行动项收口耗时分布，可导出摘要卡片图（PNG）。

## 任务与目标

待办按三分诊（今天必须 / 卡住别人 / 可绕开）自动归类，可手动调整；也可切「按日期」视图——到期待办与目标按日排布（逾期置顶、今天/明天/后天具名、无期限沉底），直接回答"某天要交什么、这周负载怎样"；勾选即完成，改期与搁置在分诊视图操作。复选框是唯一状态开关（勾选闭环、再点恢复）；「搁置」一键留底可恢复，彻底清除在已结束区（红色删除按钮）。目标带期限时间条与进度轨迹。「从项目扫描待办」：授权一次你的项目根目录，各项目 `TODO.md` 的未完成项自动聚进来（打开应用自动扫，只进不回写源文件）。

## 设置

偏好中心（界面字号缩放、阅读行宽、界面字体——即时生效并记住）/ 数据（全量导出导入、自动备份开关与周期、可读档案、存储保护、换机指引、**历史数据搬家**——① 浏览器书签与稍后读：Chrome/Edge/Firefox「导出书签」或 Raindrop / Pocket / Instapaper 导出的 HTML 按网址去重带进条目库，文件夹转标签；② Markdown 文件夹：Obsidian / Logseq / 思源导出的文件夹或任意 md 库宽容导入为速记，按内容去重，文件夹转标签；③ 笔记应用数据：flomo 导出的 HTML、Notion 导出的 zip、Evernote / 印象笔记导出的 .enex，一律导入为速记）/ 采集偏好（兴趣域、屏蔽词、AI 兴趣画像归纳、转接地址——没有权重参数，校准由你的投票自动完成）/ 工具轮盘（桌面版任何地方呼出的环形快捷入口；格位可编辑：打开页面、速记浮层、立即抓取、打开网址、置顶窗口等动作，最多 8 格；网页版用命令面板）与**键盘快捷键**（速记、命令面板、帮助、设置、轮盘、置顶窗口、剪贴板速记七个键位可自定义：设置 → 键盘快捷键，点键位后按下新键即可，撞键会被拦下；帮助页快捷键表同步显示当前键位）/ 错误日志（查看/导出/清空）/ 云端同步（含设备同步：记录级增量，多设备各自读写、新者为准，只传变过的记录）/ 通知（待办到期、复盘节奏、日报就绪三类提醒；桌面版另有 **Shell 通知桥**：一键配置后，终端里在任意命令后面加 `pdone 你的消息`，命令一结束 PWORK 就弹系统通知——设置 → 通知 里一键配置与测试）/ AI·BYOK / 关于（版本信息、检查更新）/ 重看首访引导。视觉主题的切换在**侧边栏左下角**（暗色 / 跟随系统 / 明亮三格），旁边是 GitHub 开源入口。

## 配置速查（要不要配、怎么配）

- **自动备份**：建议所有人开（每周）。桌面版存 AppData\backups，浏览器版存下载文件夹。
- **AI**：可选。桌面版把 `PWORK_LLM_API_KEY=…` 写进 `%APPDATA%\com.pwork.workbench\gateway.env` 重启即用；不配则规则引擎兜底，全功能可用。
- **云端同步**：默认不需要（纯本地一切可用）；想 24 小时自动抓源的人按帮助页配置指南五步走。
- **转接服务**：公共转接频繁超时才需要换自建地址。

## 数据在哪、怎么丢不了

桌面版：主库是应用数据目录下的 **pwork.db**（单文件，可直接复制备份），同目录的 **vault** 文件夹是它的只读镜像（每条数据一个 Markdown 文件，Obsidian 等工具直接可读），自动备份在 backups 文件夹；速记图片附件在 **attachments** 文件夹（字节不进数据库与 JSON 备份，随可读档案 zip 带走）。网页版：数据在浏览器内（可随时导出）。自动备份、换机迁移、镜像重建都在 设置 → 数据。
