## 2. 功能清单（已交付）

- **CLAP 四步向导**（对比→逻辑→认知→规划）+ 3 分钟快答版；场景包差异化（情绪词库/决策偏差检查单/习惯回路三问/SMART 检查）
- **团队会议模式**：七阶段（角色分配→破冰→事实→原因→规律→计划→归档）、先写后亮、复盘墙
- **防偏差引擎**：追责/自责/空洞承诺/后见之明/借口五类措辞拦截改写、顺序强制、可控性三级、归纳"待验证"、未写行动禁止归档
- **因果循环图白板**：表单建模 + 自动布局 + 触屏/鼠标拖拽 + 回路检测命名 + 根因判定 + 双循环并排对照 + 模板库（飞轮/恶性/成本环）
- **工具箱**：SWOT 2×2（SO 策略提示）、逻辑树（MECE 分解）、5Why、决策/习惯专属工具
- **Double Check 六维检验**（五维勾选 + 环节质量自动自检）、认知资产库（检索/回访/模式警示）、聚合分析页、月度 HTML 报告
- **AI 教练（BYOK）**：深挖追问 + 措辞改写，规则引擎兜底
- **平台**：PWA 离线、本地通知提醒、打印样式、键盘快捷键（N/?//、向导←→）、明暗主题、无障碍

## 3. 核心数据实体（供工作台数据层规划参考）

```
ReviewRecord { id, type, scenario, status, quick,
  clap: { comparison{goals,results,gaps,emotion?},
          logic{causes, cld?, swot?, tree?},
          acknowledge{insights,doubleLoop},
          project{actions(if-then,…)} },
  meeting?, doubleCheck?, summary[], thinkingQuestion? }
ActionItem { id, reviewId, kind(stop|continue|start), text, ifThen, due, status, closedAt }
InsightRecord { id, reviewId, text, patternGroup, kind, verified, revisit[], createdAt }
```

导出格式 v1：`{ version:1, exportedAt, reviews[], actions[], insights[] }`（迁移时冻结为工作台包裹的子结构）。

## 4. 与工作台的对接点（P1–P3 落地）

| 对接点 | 方向 | 说明 |
|---|---|---|
| 行动项桥接 | 回路 → 工作台任务库 | ActionItem 通过 `taskId` 引用任务库条目；**任务库是 SSOT**，复盘侧不拷贝 |
| 目标只读引用 | 工作台 → 回路 | 向导 C 步从目标模块只读带入，替代手动输入 |
| O/T 候选池 | 采集 → 回路 | SWOT 的 O/T 格引用采集系统 `otFlag` 条目（设计见 04 文档 §7） |
| 复盘预填 | 工作台 → 回路 | 周复盘自动汇总本周任务完成/延期、目标 delta |
| 信号触发 | 工作台 → 回路 | 任务延期 N 次/模式警示第 3 次 → 推荐开复盘 |

## 5. 子模块化改造清单（W3 已完成 2026-08-31）

1. ~~**数据层接口化**~~ ✅ **W3 决议（C-3）：统一 Dexie 库**。未引入 `StorageAdapter` 接口——回路三表（reviews/actions/insights）直接并入工作台 `pwork-workbench` 库（schema v3），模块内 `db/schema.ts` 改为 re-export 根 schema 的 shim，模块代码零改动。理由：接口抽象在 SQLite（C3/Tauri）到来时才真正需要，届时以根 schema 单点替换；行动项桥接（taskId 同库查询）也因此简化。
2. ~~**路由收敛**~~ ✅ 页面原样迁为 `/review/*` 子路由（`src/modules/review/pages/`，App.tsx 懒加载 + `<ReviewLayout>` 包裹）；模块内互链已改写为 /review 前缀。FUPAN 全局快捷键（N/?//）未挂载——由壳统一提供（N=速记浮层、⌘K=命令面板）；向导内 ←→ 切步为组件自管，不受影响。
3. ~~**设计令牌对齐**~~ ✅ 根令牌即 v3；模块 `ui.css` 全量作用域化到 `.review-root`（含 @media/多行选择器处理），`base.css` 的 `.page-head/.kicker/.coach-say` 以作用域规则并入；按钮沿用壳设计系统规格。
4. ~~**文案/知识卡独立包**~~ ✅ `content/` 原样随迁（零 UI 依赖结构保持）。
5. ~~**导出格式升版**~~ ✅ 备份包裹升 **v2**：`entities` 新增 `reviews/actions/insights/tasks`（+ sources/items/collectConfig）；导入兼容 PWORK v1/v2 与 **FUPAN v1 旧格式**（顶层 reviews/actions/insights），按 id + updatedAt last-writer-wins 合并。

**行动项桥接（03 §4 第 1 项）同步落地**：归档时行动项自动落任务库（TaskItem，`origin={kind:'review', refId: actionId}`），ActionItem 回写 `taskId`；任务勾选闭环反向同步 ActionItem 状态（任务库是状态 SSOT，FUPAN 闭环率统计口径不变）。目标只读引用、O/T 候选池、复盘预填仍按计划在 W4。
