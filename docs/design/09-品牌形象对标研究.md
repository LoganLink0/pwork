## 一、对标矩阵

### 1. WorkBuddy / Miora（腾讯，直接同类）

- **是什么**：腾讯的一体化 AI 办公工作台（AI Agent for everyday office work）；旗下创意智能体形象 Miora。行业趋势：AI 产品把 IP 角色直接当作 Logo（Grok Bot、Coze、豆包、Kiro 同向）——角色即 Logo 提高辨识度。
- **怎么做 IP 全案**（实測案例：用 Miora 两小时产出完整全案）：①**先立人设规范再出图**——角色档案卡（物种/性格/主色/名字/爱好/口头禅/MBTI）+ 标准三视图，后续一切延展都靠这套规范保持一致；②任务拆品类——表情包贴纸（大笑/生气/打招呼/疑惑/眨眼/唱歌/加油/星星眼/大哭九种情绪，靠眼神、嘴型、动作和小图形区分，「不是把同一个角色复制九遍」）+ 故事场景延展；③周边/包装/详情页；④3D 打印可制造参考。
- **关键教训（一致性）**：案例中一款颈枕漏掉了角色最核心的红围巾，「整个 IP 一致性就断了」——核心特征清单必须出现在每一个延展物上，漏一次即破功。
- **对 PWORK 的意义**：同类产品已把角色当 Logo 与产品声音；全案流程可直接沿用其结构。

### 2. Duolingo / Duo（多邻国猫头鹰）

- **是什么**：绿色猫头鹰（原型为眼镜鸮），品牌声音由角色统一承担——产品内与营销外的每个触点同一种语气；「不确定、爱玩梗」的性格让它成为 2020 年代最有辨识度的品牌声音之一。
- **怎么做**：配色来历非典型（绿色起源故事成了传播素材）；形象多年多次重绘迭代（定稿不是终点）；表情与动画系统支撑角色承载情绪。
- **启示**：小 P 的说话语气应当由角色统一承担（本项目既有声音：平实、先听后递）；重绘迭代是常态，规范稿约束的是特征而非某一帧画面。

### 3. 知乎 / 刘看山

- **是什么**：2014 年通过知乎吉祥物设计大赛征集诞生的北极狐（作者鱼正义）；社区认知度最高的品牌视觉符号。
- **怎么做**：**一个记忆点特征**——突出的鼻子是造型核心，官方形象基本以侧面示人（一个视角即可辨识）；独特标志短尾巴写进人设故事；表情包首发即同步建粉丝组织「冰山俱乐部」；官方拟人化账号运营（发活动、写未来信）；2025 年仍有社区用 AI 保持其角色一致性做图的讨论。
- **启示**：记忆点靠「一个特征 + 一个惯用视角」立住，不靠细节堆砌；用户共创（征集）是可选项；表情包与角色运营同步启动。

### 4. GitHub / Octocat

- **怎么做**：Octocat 是注册商标 + 版权登记；使用规范明确——可做个人头像、可指代 GitHub；不可做自家产品 Logo、企业头像、周边商品（需书面许可）；Octodex 画廊沉淀官方再创作形象（梗形象也收），但只收 GitHub 关联人员的作品。
- **启示**：使用规范要早立（能做什么/不能做什么一页说清）；形象的权利与产品的商标分开管理；官方衍生画廊只收官方。

### 5. Rust / Ferris（螃蟹）

- **怎么做**：CC0 公共领域授权（作者放弃版权），社区自由使用与二创；身份是**非官方**社区吉祥物（社区自发拥立）；Rust 的商标（词 + 齿轮 Logo）由基金会商标政策单独管理，与吉祥物权利分离；周边个人/小规模使用自由。
- **启示**：对开源项目，吉祥物宽松授权反而壮大社区生态；「官方规范形态」与「社区自由衍生」可以并存（权利分层）。

### 6. Go / Gopher

- **怎么做**：独立艺术家 Renée French 创作（原为电台 T 恤形象后改编）；使用受 Go 品牌指南管理，超出指南需书面批准；社区惯例为作品署名原作者。
- **启示**：创作者归属要写明（PWORK 的形象若为 AI 生成 + 规范稿，同样需要在规范页写明生成方式与权利归属）。

### 7. 熊本熊（Kumamon）

- **怎么做**：熊本县买断著作权、**零版税免费授权**换海量曝光——但有条件：官网申请、审核「有助于宣传熊本县」、不得损害形象；角色人设一句话说清（「公务员熊」）；专业运营（操偶师、跨界合作、如艺人般经营）。
- **启示**：人设必须一句话能转述；若日后开放周边/商用，走「申请 + 条件」模式而非完全放开或完全收紧。

### 8. 拖拖工作室IP频道（小红书 3083 粉，2026-11-11 用户指定对标，七篇笔记全览）

- **是什么**：原创 IP 孵化工作室，自我定义「通过可爱的小东西来讲好故事」；本体角色是一只**灰色蓬松小猫团**（蜡笔粗轮廓 + 点点眼 + 微笑），旗下延伸小熊吧唧、小恶魔巴特、蛋黄小卜等多个小 IP。
- **怎么做**：①角色永远「在做事」——趴卧/穿西装开会/背翅膀飞过云层/打网球，每张封面一个动作一个故事，配一句话对话气泡（「当然是用飞的」「汪汪」）；②**Vol 连续编号**（Vol.10/11/12…）做系列感与追更动力；③「优质 IP 分享」联动其他 IP 作者（vol.1 pumupuz 麻薯、vol.2 小玉yuy）做引入流量与跨界；④视觉语言：大字问题式标题 + 极简角色插画，识别成本极低。
- **启示**（已落提示词 v2）：①蜡笔涂鸦质感 + 简笔轮廓比精修 3D 更暖更易记，且与 P 字标平面基因同源；②角色特征清单必须极简且每次全保留（灰猫=圆团/点眼/微笑/粗轮廓四件）；③Vol 编号让内容成系列可持续；④对话气泡是性格表达的最低成本载体。



## 二、由此提炼的小 P 设计决策（3.1 批的执行输入）

1. **人设一句话**：「它先听，再递给你」——安静、可靠、不喧哗的搭档；对应产品事实：速记/抓取只在本地（先听），日报/PPT/行动项整理好递到面前（递给你）。不编造无关性格设定。
2. **形态方向（2026-11-11 用户定调：贾维斯式 AI 生命 + P 字形即身体）**：小 P 没有实体小动物形态，本体为**字母 P 的光态 AI 生命**——字母 P 由纯净的橙色光粒与光环构成（竖笔为躯干、顶部封闭圆环为会竖起倾听的大耳朵），悬浮、呼吸、可聚散；PWORK 本就是 AI 工作台（AI 网关/AI 问答/抓取管线），「一只只住在你电脑里的 AI 生命」直接符合产品事实，且贾维斯原型即「伙伴型 AI」；大厂 AI 在云端，小 P 只属于你——叙事更强。**P 字形剪影在任何姿态必须可辨**（修正记录：v4 初版锚定段丢失 P 字形语义被用户打回——光核+光环+粒子是通用 AI 风格，任何产品都能用；字形剪影才是身份本体）。避坑：不做钢铁侠红金配色与 arc reactor 仿制（IP 撞车），只用品牌色系。
3. **质感方向（2026-11-11 定分层质感策略，随形态方向细化）**：产品内触点（圆钮/空态/引导/错误页）为扁平矢量/发光符号——光态生命的产品内形态本身就是发光符号，扁平即符合设定；产品外物料（介绍页主视觉/宣传图）允许升维演绎（3D 全息/厚涂）——同一角色同一特征清单，不同介质不同演绎，角色本体由特征清单与性格定义、不由单一渲染技术定义（熊本熊平面标志与实体玩偶装并存、LINE FRIENDS 扁平贴纸与 3D 手办并存，同法）。历程留档：v1 曾定 3D 盲盒（随 WorkBuddy 对标）、v2 曾改蜡笔涂鸦（随拖拖对标）——两次都是「对标决定风格」的同一类错误；**对标研究取方法论（角色在做事/系列编号/性格气泡/特征极简），视觉风格只从自身品牌基因与产品事实推导**。扁平的已知代价（如实记录）：表情容错低，表情画不好就是「死鱼眼/假笑」——表情集多轮抽卡精修的质量门槛高于质感风。
4. **核心特征清单**（每个延展物必须全保留，漏一即返工——Miora 案例教训）：**P 字形剪影任何姿态可辨**；圆环=耳朵（耳尖内侧 #E8833A）；竖笔=躯干与递出的手；光粒与光环（AI 生命属性）；暗部 #b0500f 过渡与米色底（#f5f4f1）触点。
5. **表情集对齐用户旅程**（8–10 个）：欢迎、倾听中、思考中、回答完成、提醒（备份/到期）、出错安慰、庆祝（任务闭环）、晚安——每个表情靠眼神/动作/小图形区分，禁止同形复制。
6. **触点清单与克制红线**：问小 P 圆钮（默认/思考/完成三态）、空态页、首访引导、错误页安慰态、关于页；**数据与设置类界面不出现**（工具感优先，可爱感只在伙伴性场景）。
7. **权利分层**（拍板建议）：官方规范稿标记「官方形态」，形象本体建议 **CC BY 4.0**（保留版权、要求署名——登记与授权自洽），允许社区二创；**不选 CC0**（放弃版权的声明，与版权登记自相矛盾）。AI 生成参与要如实说明：司法先例（北京互联网法院 2023 年 AI 文生图案）认定人类智力投入足够时 AI 生成图构成美术作品，角色档案卡/特征清单/提示词文件已入仓构成智力投入证据链；按《人工智能生成合成内容标识办法》（2025-09-01 施行），对外发布的生成图需按规定做显式/隐式标识。作品登记（中国版权保护中心，自愿）在形象定稿矢量化后办理，登记仅是初步证明。商用周边远期走「申请 + 条件」（Kumamon 模式）；商标保护（品牌符号的排他使用）另议，与版权分工不同。
8. **交付物清单**（照 WorkBuddy 全案结构裁剪到独立开发者体量）：角色档案卡 → 标准三视图 → 表情集 → 产品触点落地图 → 规范一页（含使用规范与禁止用法）；盲盒/周边/3D 打印为远期可选项，不在 1.0 范围。
9. **流程**：规范稿定稿 → AI 生成候选 v1/v2…（版本化归档 `docs/assets/mascot/`，禁止覆盖旧版）→ 用户拍板 → 矢量化（SVG，全站任意缩放）→ 触点落地 → 物料与介绍页重出。

## 二点五、角色规范一页（草案 v1——文字部分即项目规范；图片位待即梦候选定稿后填充）

> 本节为 3.1 的规范正文。文字部分现在即可评审拍板；图片候选按 提示词-v4.md 生成后填入下方图片位。

**角色档案**

| 项 | 设定 |
|---|---|
| 名字 | 小 P（Perfect Partner 完美搭档） |
| 本体 | 字母 P 的光态 AI 生命（无实体、无五官脸——圆环即脸，以环的姿态与光效表达情绪） |
| 性格 | 冷静、可靠、克制、关键时刻在线；不聒噪，说完就做 |
| 人设一句话 | 它先听，再递给你——只住在你电脑里的 AI 生命 |
| 口头禅 | 「在。」「整理好了，请查收。」 |

**核心特征清单**（每个延展物必须全保留，漏一即返工）

1. **P 字形剪影任何姿态可辨**——竖笔为躯干、顶部封闭圆环为大耳朵；
2. 圆环内侧与点缀用橙 #E8833A，笔画暗部 #B0500F，身体主体米白 #F5F4F1（深色场景下身体转半透明光态）；
3. 环口伸出的圆掌小手（递出的动作载体）；
4. 稀疏光粒与细光环（AI 生命属性，密度克制不堆砌）。

**状态系统**（产品内三态 + 表情集八态）

- 产品内三态：默认（呼吸明暗）/ 思考（光粒绕核旋转）/ 完成（环口托出发光卡片）；
- 表情集八态：欢迎 / 倾听（圆环竖起+声纹波纹）/ 思考 / 递出 / 提醒（铃铛+光环脉冲）/ 安慰（暖光罩住）/ 庆祝（粒子星环）/ 晚安（光核转月白闭眼）。

**触点清单**：问小 P 圆钮三态、空态页、首访引导、错误页安慰态、关于页、介绍页主视觉（物料层）。
**禁止用法**：数据与设置类界面不出现；不做说话框轰炸（每屏至多一句气泡）；不做红金钢铁侠配色；不做 arc reactor 仿制；剪影不可辨认为 P 的延展物一律返工。

**使用规范**：形象本体 CC BY 4.0（署名-相同方式不强制，社区可二创），官方形态以本页特征清单为准；对外发布的 AI 生成图按《人工智能生成合成内容标识办法》做显式标识；商用周边远期「申请 + 条件」（Kumamon 模式）；商标另议。

**图片位**（待即梦候选定稿后填充）：本体定稿 ×1 / 三视图 ×1 / 表情九宫格 ×1 / 触点落地图 ×4 / 物料图 ×3。
