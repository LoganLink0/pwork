# 09 · 品牌形象对标研究（小 P 吉祥物设计的前置输入）

> 2026-11-10 用户拍板：1.0 视觉大版本以小 P 吉祥物（Perfect Partner 角色化）为核心，参照 WorkBuddy 的 IP 设计角度选取更多对标。
> 本文档是对标研究结论与由此提炼的设计决策，是 [插件化与1.0执行计划.md](../插件化与1.0执行计划.md) 3.1 批的前置输入；
> 定稿后角色规范一页（三视图/色值/使用场景/禁止用法）追加为本文件的终稿章节。所有案例信息来源见文末链接，未查证的内容不写。

## 一、对标矩阵

### 1. WorkBuddy / Miora（腾讯，直接同类）

- **是什么**：腾讯的一体化 AI 办公工作台（AI Agent for everyday office work）；旗下创意智能体形象 Miora。行业趋势：AI 产品把 IP 角色直接当作 Logo（Grok Bot、Coze、豆包、Kiro 同向）——角色即 Logo 提高辨识度。
- **怎么做 IP 全案**（实測案例：用 Miora 两小时产出完整全案）：①**先立人设规范再出图**——角色档案卡（物种/性格/主色/名字/爱好/口头禅/MBTI）+ 标准三视图，后续一切延展都靠这套规范保持一致；②任务拆品类——表情包贴纸（大笑/生气/打招呼/疑惑/眨眼/唱歌/加油/星星眼/大哭九种情绪，靠眼神、嘴型、动作和小图形区分，「不是把同一个角色复制九遍」）+ 故事场景延展；③周边/包装/详情页；④3D 打印可制造参考。
- **关键教训（一致性）**：案例中一款颈枕漏掉了角色最核心的红围巾，「整个 IP 一致性就断了」——核心特征清单必须出现在每一个延展物上，漏一次即破功。
- **对 PWORK 的意义**：同类产品已把角色当 Logo 与产品声音；全案流程可直接沿用其结构。

### 2. Duolingo / Duo（多邻国猫头鹰）

- **是什么**：绿色猫头鹰（原型为眼镜鸮），品牌声音由角色统一承担——产品内与营销外的每个触点同一种语气；「不确定、爱玩梗」的性格让它成为 2020 年代最有辨识度的品牌声音之一。
- **怎么做**：配色来历非典型（绿色起源故事成了传播素材）；形象多年多次重绘迭代（定稿不是终点）；表情与动画系统支撑角色承载情绪。
- **启示**：小 P 的说话语气应当由角色统一承担（本项目既有声音：平实、先听后递）；重绘迭代是常态，规范稿约束的是特征而非某一帧画面。

### 3. 知乎 / 刘看山

- **是什么**：2014 年通过知乎吉祥物设计大赛征集诞生的北极狐（作者鱼正义）；社区认知度最高的品牌视觉符号。
- **怎么做**：**一个记忆点特征**——突出的鼻子是造型核心，官方形象基本以侧面示人（一个视角即可辨识）；独特标志短尾巴写进人设故事；表情包首发即同步建粉丝组织「冰山俱乐部」；官方拟人化账号运营（发活动、写未来信）；2025 年仍有社区用 AI 保持其角色一致性做图的讨论。
- **启示**：记忆点靠「一个特征 + 一个惯用视角」立住，不靠细节堆砌；用户共创（征集）是可选项；表情包与角色运营同步启动。

### 4. GitHub / Octocat

- **怎么做**：Octocat 是注册商标 + 版权登记；使用规范明确——可做个人头像、可指代 GitHub；不可做自家产品 Logo、企业头像、周边商品（需书面许可）；Octodex 画廊沉淀官方再创作形象（梗形象也收），但只收 GitHub 关联人员的作品。
- **启示**：使用规范要早立（能做什么/不能做什么一页说清）；形象的权利与产品的商标分开管理；官方衍生画廊只收官方。

### 5. Rust / Ferris（螃蟹）

- **怎么做**：CC0 公共领域授权（作者放弃版权），社区自由使用与二创；身份是**非官方**社区吉祥物（社区自发拥立）；Rust 的商标（词 + 齿轮 Logo）由基金会商标政策单独管理，与吉祥物权利分离；周边个人/小规模使用自由。
- **启示**：对开源项目，吉祥物宽松授权反而壮大社区生态；「官方规范形态」与「社区自由衍生」可以并存（权利分层）。

### 6. Go / Gopher

- **怎么做**：独立艺术家 Renée French 创作（原为电台 T 恤形象后改编）；使用受 Go 品牌指南管理，超出指南需书面批准；社区惯例为作品署名原作者。
- **启示**：创作者归属要写明（PWORK 的形象若为 AI 生成 + 规范稿，同样需要在规范页写明生成方式与权利归属）。

### 7. 熊本熊（Kumamon）

- **怎么做**：熊本县买断著作权、**零版税免费授权**换海量曝光——但有条件：官网申请、审核「有助于宣传熊本县」、不得损害形象；角色人设一句话说清（「公务员熊」）；专业运营（操偶师、跨界合作、如艺人般经营）。
- **启示**：人设必须一句话能转述；若日后开放周边/商用，走「申请 + 条件」模式而非完全放开或完全收紧。

## 二、由此提炼的小 P 设计决策（3.1 批的执行输入）

1. **人设一句话**：「它先听，再递给你」——安静、可靠、不喧哗的搭档；对应产品事实：速记/抓取只在本地（先听），日报/PPT/行动项整理好递到面前（递给你）。不编造无关性格设定。
2. **形态同源**：从现有 P 字标长出来（圆、耳朵、伸出的圆手），另起炉灶会断掉「P = Perfect Partner」的既有叙事。
3. **核心特征清单**（每个延展物必须全保留，漏一即返工——Miora 案例教训）：耳朵（先听）、圆手（递给你）、圆滚滚比例、品牌色对（#e8833a / #b0500f）与米色底（#f5f4f1）。
4. **表情集对齐用户旅程**（8–10 个）：欢迎、倾听中、思考中、回答完成、提醒（备份/到期）、出错安慰、庆祝（任务闭环）、晚安——每个表情靠眼神/动作/小图形区分，禁止同形复制。
5. **触点清单与克制红线**：问小 P 圆钮（默认/思考/完成三态）、空态页、首访引导、错误页安慰态、关于页；**数据与设置类界面不出现**（工具感优先，可爱感只在伙伴性场景）。
6. **权利分层**（拍板建议）：官方规范稿标记「官方形态」，形象本体建议 **CC BY 4.0**（保留版权、要求署名——登记与授权自洽），允许社区二创；**不选 CC0**（放弃版权的声明，与版权登记自相矛盾）。AI 生成参与要如实说明：司法先例（北京互联网法院 2023 年 AI 文生图案）认定人类智力投入足够时 AI 生成图构成美术作品，角色档案卡/特征清单/提示词文件已入仓构成智力投入证据链；按《人工智能生成合成内容标识办法》（2025-09-01 施行），对外发布的生成图需按规定做显式/隐式标识。作品登记（中国版权保护中心，自愿）在形象定稿矢量化后办理，登记仅是初步证明。商用周边远期走「申请 + 条件」（Kumamon 模式）；商标保护（品牌符号的排他使用）另议，与版权分工不同。
7. **交付物清单**（照 WorkBuddy 全案结构裁剪到独立开发者体量）：角色档案卡 → 标准三视图 → 表情集 → 产品触点落地图 → 规范一页（含使用规范与禁止用法）；盲盒/周边/3D 打印为远期可选项，不在 1.0 范围。
8. **流程**：规范稿定稿 → AI 生成候选 v1/v2…（版本化归档 `docs/assets/mascot/`，禁止覆盖旧版）→ 用户拍板 → 矢量化（SVG，全站任意缩放）→ 触点落地 → 物料与介绍页重出。
