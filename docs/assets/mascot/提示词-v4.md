## 即梦操作要点

1. 先跑提示词 1 两版方向各抽几张，定一个方向再全套延展；
2. 一致性三件套：同一参考图 + 智能参考 + 「保持角色一致」；
3. 特征锚定段一字不改带在每条开头（核心特征漏一次即断）；
4. **配色红线**：只用 #E8833A / #B0500F / #F5F4F1 / 深色底——禁止红金钢铁侠配色（IP 撞车）；
5. **P 字形剪影检查**：任何姿态与光效下，眯眼看剪影必须仍认得出是字母 P——认不出即废稿；
6. 生成结果按版本归档回 `docs/assets/mascot/`，命名 `mascot-<用途>-v<N>.png`。
