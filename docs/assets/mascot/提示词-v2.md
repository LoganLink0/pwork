## 即梦操作要点（同 v1，已查证）

1. 提示词 1 多抽几次挑定稿，定稿图作全套参考图锚；
2. 一致性三件套：同一参考图 + 智能参考 + 提示词写「保持角色一致」；
3. 特征锚定段一字不改带在每条开头（拖拖教训：核心特征漏一次即断）；
4. 画面无文字（界面文案由应用渲染）；
5. 生成结果按版本归档回 `docs/assets/mascot/`。
