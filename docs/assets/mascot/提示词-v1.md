## 即梦操作要点（已查证）

1. **先定稿本体再延展**：提示词 1 多抽几次挑定稿；这一张是全套一致性的锚。
2. **一致性三件套**：所有后续提示词挂同一张定稿参考图 + 使用「智能参考」（选角色特征）+ 提示词里写「保持角色一致」；图片生成 4.0 支持多图参考。
3. **特征锚定段一字不改**地带在每条提示词开头（对标案例教训：核心特征漏一次，一致性就断）。
4. **画面一律无文字**：文字后续由应用界面/设计稿统一渲染，生成图带字反而难清理。
5. **色值直接写进提示词**（#E8833A / #B0500F / #F5F4F1），与 tokens.css 记录对同源。
6. 定稿与成图按版本归档回本目录，命名 `mascot-<用途>-v<N>.png`。
