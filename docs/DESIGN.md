# DESIGN.md · 品牌契约（「冷静的工作台」设计系统 v4）

> **唯一事实来源**是 `app/src/styles/tokens.css`（令牌）——本文档是人读版契约，按开源设计系统包通行的九节结构组织（对照 open-design 的 design-systems 约定）；应用内实时样例在 `/design` 页；机器校验：`cd app && npm run validate:design`。
> 纪律出处：开发复盘 7.1 / 7.2 / 3.28 / 3.35 / 3.66–3.68，docs/design/09-品牌形象对标研究.md。

## 一、视觉主题与氛围

**一句话**：冷静的工作台——暖中性灰打底、唯一琥珀强调色，工具不该比内容更吵；伙伴感由 P 字标动效承担，不由插画与吉祥物承担（吉祥物生成线已废弃，研究存档见 docs/design/09）。

**三条立意**（每条都有验收口径）：

1. **色必载义**：颜色只用于承载信息（分类 / 来源 / 状态 / 期限四个维度）。判断标准：去掉这个颜色，信息是否丢失。
2. **单字族**：全局一套无衬线字族，层级只靠字号 / 字重 / 留白。
3. **说人话**：界面文字平实描述事实与做法（详见第八节）。

**反面清单**（不做什么）：不做大面积类别色填充；不做彩色阴影；不做彩色 emoji；不做渐变与玻璃拟态；不做第二强调色；不做「好看一点」式的无方向改动——改什么都走 24 个动作之外的四条规矩与检查清单。

## 二、色板与角色

**取值纪律（P-013 同框对比）**：色值唯一出处是 tokens.css 的 primitive 层（`--p-*`），语义层只引用；组件里出现新的色值字面量即违规，校验器按基线比对（现状 9 个文件 47 处已登记，新增即报）。同族色值验收时排成一行同框核对。

| 类别 | 令牌 | 亮色 | 用途 |
|---|---|---|---|
| 背景 | `--bg` / `--surface` / `--surface-2` | #f7f3ea / #ffffff / #fbf8f2 | 页面 / 卡片 / 凹陷区 |
| 边线 | `--line` / `--line-strong` | #e8e2d5 / #d2cbbd | 分隔 / 控件描边 |
| 文字 | `--ink` / `--ink-soft` / `--ink-faint` | #211e1a / #66625a / #6b665e | 正文 / 次要 / 弱化（三级对比必须分明，弱化档也要过 AA 4.5:1） |
| 强调 | `--accent` / `--accent-deep` / `--accent-text` | #e8833a / #b0500f / #a34e12 | 唯一强调色：CTA / 选中 / 链接；deep 用于按钮底（白字实测 5.25:1），text 用于文字 |
| 类别 | `--cat-good/need/insight/action` | 绿 / 赭 / 蓝 / 红系 | **只作 3px 边线与 12px 标签**，禁止大面积填充 |
| 模块标记 | `--m-input/process/output/review` | 蓝 / 绿 / 赭 / 琥珀 | 复用类别色取值，用途仅三种：侧边栏选中 3px 左线 / 模块卡标签 / 面包屑点 |
| 语义 | `--danger` / `--ok` | #b8443a / #2f7d52 | 错误 / 成功 |

**成对命名**（shadcn 约定，新组件优先使用）：`--fg-page / --fg-card / --fg-muted / --fg-faint` 为各表面的前景对；`--fg-on-accent` 为实底强调按钮上的文字色。

**对比度预算**：手算值已固化进 tokens 注释（正文 4.5:1 起，按钮底 5.25:1，弱化档暗色 5.17）；全表现由 `npm run validate:design` 自动计算，改任何色值先跑它。

**暗色主题**：同套令牌换值（两处定义必须逐项一致，校验器做漂移断言——历史上两块已经漂过一次）；**明度区间要拉开**：卡面与背景分离度、文字三级对比是暗色验收线（塌过一轮，复盘 7.2）。主题切换只改变量令牌，布局与结构保持不动。

## 三、字体排印

**单字族**：`--font-body` 系统栈（-apple-system → PingFang SC → MiSans → HarmonyOS Sans SC → Microsoft YaHei → Noto Sans SC → Segoe UI）；`--font-body-override` 是偏好中心的覆盖口——用户偏好缩放不改令牌结构。

**字号阶梯（8 级，组件禁止自造数值）**：`--fs-xs 13`（标签 / 说明 / 元信息）→ `sm 14`（次要 / 引导句）→ `md 17`（正文）→ `lg 19`（卡片标题）→ `xl 21`（展示性区块标题）→ `h1 29`（页面标题）→ `hero 33`（首页标语 / 仪表盘 Hero）→ `num 25`（统计数字，恒配 `tnum` 等宽数字，计时器倒计时禁止跳动）。全部经 `calc(基础值 * var(--font-scale, 1))` 随偏好缩放。

**收敛口径（机械断言可验）**：h1 = 页面标题一档；内容区标题 = lg；引导句 = sm；tnum 元信息 = xs；全站一致，Hero 与统计数字为令牌角色。

## 四、布局与间距

- **间距 8px 基**：`--sp-1..7` = 4/8/12/16/24/32/48。页面留白节奏统一 `sp-5` 起。
- **圆角派生尺（v4 新）**：`--radius: 10px` 是唯一基准——`--r-sm: calc(var(--radius) * 1)`（10，控件）→ `--r-md: ×1.4`（14，浮层 / 内嵌件：toast、quick-add）→ `--r-lg: ×1.8`（18，卡片容器：set-card、mcard、tile、digest-item、task-card、src-table、note-list、editor）；胶囊用 99px。卡片层不许用 14。改 `--radius` 一处，整把圆角尺跟着走。
- **阴影单体系**：`--shadow-1`（静置）→ `--shadow-2`（悬停抬升）→ `--shadow-pop`（弹层）；投影暖棕化与品牌同温。禁止彩色阴影。抬升分层的语义别名 `--raised-1/2/3` 指向同一组值。
- **布局常量**：`--content-w 1200px` 内容列 / `--sidebar-w 240px`（≤1279px 收 200px）/ `--topbar-h 56px`；≤768px 侧栏消失、底部导航接管（60px + 安全区）。横滑容器右缘 28px 渐隐提示可滚动。

## 五、组件

**五态清单（每个交互组件写全）**：default / hover / focus-visible / active / disabled。悬停无变化的可点元素视同缺陷（2026-10-24 模板卡事故，复盘 3.28）。

**核心约定（新页面对照清单）**：

- 表单卡：`set-card > h2 + .desc + .set-body`，行 `set-row`（label 130px 定宽）。
- 控件尺寸基线（全站实测口径，机械断言可验）：主 / 次按钮 38px 高（.btn-primary/.btn-ghost），小按钮 26px（.mini-btn/.btn-small），输入框 36px（.input，textarea 按内容高例外）；回路工作台输入框同走主壳 .input 规格（36px + r-sm + 焦点外发光）。
- 输入焦点：描边变 accent + 3px 15% 外发光（box-shadow，非 outline 改形）；无边框行内输入（如快速添加）用容器 :focus-within 给反馈。
- 状态徽章 / 边线遵循模块标记三用途；空态卡用 quiet（虚线 + 降底 + 无阴影），让有数据的卡主导第一眼。
- 演示视频卡（首访引导与帮助 - 快速上手共用模式）：`<video autoplay loop muted playsinline>`，`object-fit:cover` 封顶高（卡式 190px / 行式 150px）+ 底描边，说明句 fs-sm 次要色、卡名加粗主色；引导用 2×2 网格（≤700px 单列），帮助用左视频右文行式。
- 鼠标语义：真 `button` 与 `[role=button/checkbox/radio/tab]` 一律手型；div/span 扮演交互元素必须带 role + tabIndex + 键盘事件。
- 每个新页面上线前对照本文件 + `/design` 样例页核一遍（复盘 7.2 预防条）。

## 六、动效与交互

- **令牌**：`--dur-1 120ms`（按压 / 着色）→ `--dur-2 200ms`（抬升 / 展开）→ `--dur-3 320ms`（路由入场 / 弹层）；统一缓动 `--ease` cubic-bezier(.22,.61,.36,1)；完成态回弹用 `--ease-spring`。
- **铁律：只动 transform 与 opacity。**
- **既有模式**：路由切换内容上浮淡入（page-in）、弹层 pop-in、按钮按压 scale(.98)、卡片悬停 translateY(-1~-2px) + shadow、瓦片箭头 hover 位移 2px、错误条入场 bar-in + 呼吸点；历史错误静默（不弹条）。
- **P 字标三态**（伙伴感的唯一载体）：静置 4s 呼吸 → 会话中 1.8s 慢脉冲 → 轻点弹跳，配 shimmer；3 秒延迟渐显防短对话闪烁。纯 CSS，只动 transform/opacity。
- **总闸**：`prefers-reduced-motion` 全局生效（base.css）；reduced 用户零动效。

## 七、图标与影像

- 界面图标一律用 `app/src/components/shell/icons.tsx` 的 `Icon` 组件（24×24、描边 2、`currentColor`，几何取自 Feather 公开图形）。常规尺寸：导航 18 / 卡头 20 / 行内 14 / 空态 32。
- 彩色 emoji 不进界面——Windows/macOS 各画各的且带彩色，与单色体系冲突（2026-10-23 全站清除）。
- 需要语义色的图标由使用处包 span 着色：停 = cat-action、继续 / 达成 = cat-good、开始 = accent-text、增强回路 = cat-good、恶性 = cat-action。
- 保留的单色字符：✓ ✗ ★ ✦ ✕ ＋ → ↗（线性字形且承载语义）。导出文档（md/PPT/HTML）内的 emoji 属文档内容，不受本节限制。
- **影像**：不做插画与吉祥物；产品内影像 = 真实操作录屏（webm，960×600@8fps）。按钮文字不带装饰符号，直接说事；进行中状态用「……中」表达。

## 八、语气与口吻

- **说人话**：界面文字直接描述事实与做法——不自造词、不用比喻、不用缩写。判断标准：没读过任何文档的人能一眼看懂。
- **检查表机制，不是自觉**（复盘 3.35）：面向外部用户的文案写完过一遍内部词清单——`本地优先 / 闭环 / 模块 / 条目 / 全库 / 预置 / 口径 / 内部编号`，grep 命中即改。
- **正反对照**：反例（自造词）「把内容丢进回路跑一遍」→ 正例「导入后自动整理，稍等片刻」；反例（功能腔）「支持多格式输入」→ 正例「支持粘贴文字、图片和文件」。新文案拿不准时回到第一节三条立意校验。
- 触点一致性：产品内与介绍页（loganlink0.github.io/pwork）同一语气；发布说明与界面文案同一把尺。

## 九、边角与变化

- **空态**：quiet 卡（虚线 + 降底 + 无阴影），文案说清「这里将来会有什么、现在怎么开始」；禁止一片空白。
- **错误三层**：ErrorBar（即时红条）/ ErrorBoundary 崩溃页（不白屏）/ 设置页日志卡——色都用 `--danger`；历史错误静默。
- **主题边界**：主题切换只改令牌（七套思路的当前实现 = 明暗两套）；明度区间拉开是暗色验收线。
- **字号缩放边界**：`--font-scale` 由偏好中心驱动，全阶梯 calc 跟随；200% 文字缩放下布局不破是验收线。
- **验收纪律（双探针）**：机器扫描（lint / 测试 / 本文档校验器）+ 用户视角走查，缺一即盲区；扫描零发现必须注明覆盖面（复盘 3.68）。
- **待补**：超长文本截断、离线态、升级迁移的视觉规格待走查后补全本节（双探针走查项）。
