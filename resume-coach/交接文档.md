# 交接文档 · Resume Coach（简历辅导独立项目）

> 交接基准：PWORK 仓库提交 `f3ad03e`（2026-09-13）。此后本项目在独立目录演进，与 PWORK 仓库互不依赖。

## 一句话定位

简历辅导服务的独立工作台：按八步流程（自检包 → 岗位解码 → 访谈追问 → 匹配诊断 → 条目改写 → 简历稿 → 交付核对 → 面试衔接·可选）走完一个客户案例。**PWORK 只是跳转入口，本项目自持数据、构建与测试。**

## 怎么跑

```bash
npm install        # 首次
npm run dev        # http://127.0.0.1:5274
npm test           # vitest，17 个测试
npm run lint       # oxlint
npm run build      # tsc -b && vite build
```

前置仅 Node.js ≥ 20。AI 能力可选：与 PWORK 共用本地网关（PWORK 的 `app` 目录 `npm run gateway`，127.0.0.1:8788），在应用「AI 设置」选「本地网关」；不配 AI 每个功能都有手动替代。

## 迁移到新目录的步骤

1. 复制本目录（**排除 `node_modules/`**）到目标位置
2. 新目录内 `npm install`
3. `git init && git add -A && git commit`（迁移前的全部历史在 PWORK 仓库，提交号见顶部基准）
4. 迁出后**删除 PWORK 仓库内的 `resume-coach/` 目录**（避免双副本漂移；PWORK 侧边栏入口页与 README 已写成与存放位置无关的表述，无需改）
5. 浏览器数据（IndexedDB 库名 `resume-coach`）按"浏览器 + 端口(5274)"隔离，端口不变则数据无缝延续

## 目录结构与约定

```
src/
  engine/    纯函数引擎（提示词/解析/自检包/进度推导/文件提取/LLM 调用）——不碰 DOM 不碰 DB
  db/        Dexie（库名 resume-coach）+ repo（cases/caseFiles，软删除，事务化勾选）
  pages/     案例库 + 分步工作台（CaseLayout 左侧步骤栏 + CaseSteps 八块面板常挂载按步显示）+ AI 设置
  components/ArticleEditor（分析草稿逐节编辑）
  types.ts   Case / CaseFile（自有模型，不与 PWORK 共享实体）
```

- 引擎一律纯函数；页面只做装配——这条线保住了"将来再拆/换壳"的低成本
- 数据库迁移规则：字段只增不删，索引变化必须升 version（当前 v1）

## 硬约束（违反会重蹈已踩过的坑）

1. **上传必须有处理反馈**：每个文件处理完，逐条报告「提取成功 N 字 → 存为什么类型」或失败原因（扫描版 PDF / 老 .doc 有具体指引）。这是用户明确要求的契约，`extract-log` 区块 + `fileExtract.test.ts` 契约测试盯着
2. **AI 超时 240s**：思考型模型（glm-4.5-flash）对诊断这类最大提示词实测可超 150s（已两次真机复现），改小必复发
3. **不编造**：诊断/改写对素材里没有的证据如实标缺口，占位用（数字待补）
4. **软删除**：案例删除时案例文件一并软删除；不做物理清除
5. **弹窗输入（prompt）禁用**；confirm 仅用于确认类
6. **每个 AI 按钮必须配手动替代**，未配 Key 时置灰并指引「AI 设置」
7. 提示词里材料单件截断 3000 字（`resumeTools.test.ts` 契约锁定）——材料越录越多会把思考模型延迟推过超时线

## 数据与外部合同

- IndexedDB 库名 `resume-coach`；数据只在本机，不上传
- LLM 配置存 localStorage 键 `resume-coach-llm`；网关模式下浏览器侧 Key 是 sentinel（`pwork-gateway`），真实 Key 在 PWORK `app/.env.local`
- 模型名必须与 Key 服务商匹配（当前智谱 glm-4.5-flash 实测可用；deepseek-chat 对智谱 Key 会 400）
- 端口 5274 是外部合同：PWORK 入口页按它检测在线状态，浏览器数据也绑在它上面——**不要改端口**

## 已知坑

- **Windows 停 vite 留僵尸进程占端口**：TaskStop/关终端不一定杀掉 node 子进程。端口被占时 `netstat -ano | findstr :5274` 查 PID 后 `taskkill /PID <pid> /F`
- **ZCode 内嵌浏览器不支持文件选择框**：点「上传文件」无反应是环境限制，真实浏览器正常
- **免费档限流时段**：上游可能返回访问量过大——应用已如实显示并可重试
- jsdom 测试里 pdfjs worker 起不来：PDF 提取路径在浏览器验证，测试用 txt 走同一反馈分支
