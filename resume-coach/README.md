# 简历辅导 · Resume Coach

> 独立的简历辅导服务工作台：从自检包到交付包，按八步流程走完一个案例。
> 与 PWORK 相互独立（自己的数据、构建、端口），PWORK 侧边栏「案例」只是跳转入口。

## 启动（30 秒）

1. 本目录运行 `npm install`（首次）
2. 运行 `npm run dev` → 浏览器自动打开 `http://127.0.0.1:5274`
3. （可选）AI 能力：与 PWORK 共用同一个本地网关——在 PWORK 的 `app` 目录运行 `npm run gateway`，本应用「AI 设置」选「本地网关」即可；不配 AI 每个功能都有手动替代

## 它是什么

按服务手册（PWORK 仓库 `08-简历辅导场景包（服务手册）.md`）的八步 SOP 组织：

| 步骤 | 工作台区块 | 说明 |
|---|---|---|
| ① 前置自检 | 文件与材料 | 生成自检包（Word/Markdown）发客户；回收的文件**明确报告提取结果**（成功多少字 / 失败原因） |
| ② 岗位解码 | 岗位解码 | JD → P0/P1/P2 + 隐性能力词；AI 或手动 |
| ③ 深度访谈 | 访谈追问 | 按解码表逐项生成追问清单；AI 或手动 |
| ④ 匹配度诊断 | 匹配诊断 | 材料逐条对照打分 0-5；AI 或手动 |
| ⑤ 简历改写 | 条目改写 | STAR 条目化，一键收进简历稿 |
| ⑥ 反馈迭代 | 简历稿 | 多版本留存，存终稿，导出 Word/Markdown |
| ⑦ 终稿交付 | 交付核对 | 7 件交付物核对清单 |
| ⑧ 面试衔接（可选） | — | 话术卡存进材料自动亮起 |

## 数据与备份

- 数据存本机 IndexedDB（库名 `resume-coach`），不上传任何服务器
- 备份：浏览器开发者工具暂无一键导出（规划中）；当前可用 PWORK 的全量备份习惯自行 JSON 导出，或定期复制浏览器 Profile
- AI 外发范围（L2）：只有你主动点 AI 按钮的内容会发往所配服务商；其余数据全部留在本机
